# Roadmap

## V1 acceptance scope

- Complete pure engine for the fixed required/enum/string/integer/decimal/boolean contract.
- Bounded protected schema/CSV parser, redacted API/CLI and fixed exit semantics.
- Synthetic examples, source tests, installed-wheel/console tests and an independent frozen oracle.
- Publish only the fully accepted standalone MIT package, never a stub milestone.

The originating template supplies two editable stubs; an accepted release must replace them and satisfy the complete scope above. Release acceptance is recorded in trusted test/CI/publication receipts; this static roadmap defines scope and is not itself an acceptance receipt.

## Future ideas — no implementation authorization

Additional delimiters/types/constraints or a data-repair feature require a separate public contract and independent oracle before being offered as autonomous work. No dates, full JSON Schema, spreadsheet execution, real customer integration or hosted service is promised. Cosmetic changes and renamed existing projects do not count as new completed projects.
